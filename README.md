# speedtest

Небольшая утилита командной строки для замера скорости скачивания.
Скрипт выполняет серию последовательных HTTP GET-запросов к указанному
URL (обычно это большой статический файл, например «тяжёлая» картинка),
замеряет время каждого запроса, объём скачанных данных и выводит
итоговую скорость.

## Возможности

- Последовательные HTTP GET-запросы, каждый дожидается полного ответа
- Замер времени каждого запроса, включая время до первого байта (TTFB)
- Настраиваемое количество запросов, таймаут и повторы при ошибках (с backoff)
- Вывод в виде текста или JSON (`--json`)
- Никаких сторонних зависимостей — только стандартная библиотека Python

## Установка и запуск

Ничего устанавливать не нужно, достаточно Python 3.10+:

```bash
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Пример вывода:

```text
URL                   : https://example.com/big.jpg
Successful requests   : 10
Average request time  : 1.48 s
Total downloaded      : 48.53 MB
Average speed         : 3.27 MB/s (26.2 Mbit/s)
```

## Параметры командной строки

```text
url                адрес файла, который скачивать
-n, --requests N   количество последовательных запросов (по умолчанию: 10)
--timeout SEC      таймаут одного запроса в секундах (по умолчанию: 60)
--json            вывести отчёт в формате JSON
-v, --verbose      логировать каждый запрос
--version         показать версию
```

Пример JSON-отчёта:

```json
{
  "url": "https://example.com/big.jpg",
  "requests": 10,
  "failures": 0,
  "avg_time_seconds": 1.48,
  "total_bytes": 50855936,
  "total_mb": 48.5,
  "avg_speed_mb_per_sec": 3.27,
  "avg_ttfb_seconds": 0.083
}
```

## Разработка

Запуск тестов:

```bash
python -m pytest -v
```

Тесты поднимают локальный HTTP-сервер на случайном порту, поэтому
работают без доступа в интернет.
